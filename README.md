# CITY QUEST v0.3

Готовая версия для GitHub Pages.

Новые возможности: карта и GPS, фотографии Wikimedia Commons, озвучка историй через голос браузера, экран результата, Web Share, PWA install prompt и обновлённый paywall.

Загрузите все файлы в корень репозитория: main / (root).

Оплата пока тестовая. Координаты требуют полевой проверки перед коммерческим запуском.
